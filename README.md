# Our Little Day — Nagpur date itinerary

A responsive static website for a romantic day itinerary. Open `index.html` in a browser or serve this directory with any static web server.

## Included
- `index.html` — page content and itinerary
- `styles.css` — responsive editorial styling
- `script.js` — date picker, activity selection, food/café selection, and progress state
- `assets/` — six locally bundled generated mood photographs used by the page

## Images
The included images are generated illustrative mood photography. They are not authenticated photos of Cafe O'Bliss, Place Bakehouse & Coffee, Raman Science Centre, Xplore Park, Genesys School of Pottery, or Funzoo Go-Karting. The site labels this clearly. Replace them with venue-owned or verified photos if exact venue photography is needed.

## Run locally
Double-click `index.html`, or from this folder run:

```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.
